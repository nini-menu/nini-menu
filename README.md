# Каталог меню НИНИ

Статический сайт-каталог: 145 позиций, фото, составы, пищевая ценность, аллергены.
Весь контент внутри `index.html` — внешние зависимости не нужны.

## Как опубликовать на GitHub Pages

1. Зайти на github.com под своим аккаунтом, нажать **New repository**.
   Имя, например, `nini-menu`. Публичный. Создать.
2. На странице репозитория — **Add file → Upload files**, перетащить `index.html`, нажать **Commit changes**.
3. **Settings → Pages**. В разделе *Build and deployment*: Source — *Deploy from a branch*,
   Branch — `main`, папка `/ (root)`. Save.
4. Через 1–2 минуты адрес появится вверху той же страницы:
   `https://<ваш-логин>.github.io/nini-menu/`
5. Прислать этот адрес — сделаю QR на него.

## Обновление меню

Заменить `index.html` новым файлом тем же способом (Upload files → Commit).
Адрес и QR останутся прежними.
